The idea behind this project is to build a website that will keep track of bird sightings (similar to EBird for those familiar).
I'm doing this because I enjoy the concept (I'm a birdwatcher and photographer) and I want to expand/improve my tech skills with Java, PostgreSQL, and React

Currently building the back end with Java, Spring Boot, Docker, and PostgreSQL.
Working on developing a functioning REST API that connects to a Postgres database in Docker.

Once REST API functions for basic CRUD operations, I will build the front end with React. 

Down the road I plan to add analytics about bird sightings, see if I can connect to Ebird, and add more fun features.
